# AI Workbench
Static SEO site. `python build.py` builds /dist (Netlify runs this automatically).
- Add prompts/guides: edit posts.py. Cover images: put `images/<slug>.webp` in /images.
- Edit page text: pages.py. Colors: THEME in build.py ("candle" or "fresh").
- AdSense: after approval set ADSENSE in build.py (adds the script and ads.txt).
- Contact form uses Netlify Forms (turn on notifications in Netlify > Forms).
